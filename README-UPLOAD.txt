ชุดไฟล์สำหรับอัปขึ้น GitHub Pages

ให้อัปไฟล์/โฟลเดอร์เหล่านี้ทั้งหมด:

1. index.html
2. assets
   - bangsai-logo-transparent-clean.png

วิธีอัปแบบง่าย:

1. เปิด repository ใน GitHub
2. กด Add file > Upload files
3. ลากไฟล์ index.html และโฟลเดอร์ assets จากโฟลเดอร์นี้เข้าไป
4. กด Commit changes
5. ไปที่ Settings > Pages
6. Source เลือก Deploy from a branch
7. Branch เลือก main และ / (root)
8. กด Save

ลิงก์เว็บจะอยู่ประมาณ:
https://ชื่อผู้ใช้.github.io/ชื่อ-repository/

หมายเหตุ:
ไฟล์นี้ทำเป็น index.html แล้ว เพื่อให้ GitHub Pages เปิดหน้าเว็บได้ทันที ไม่ต้องเปลี่ยนชื่อไฟล์อีก
